# WebBrain 使用指南

> 分析日期：2026-08-16 · 依据：README.md、docs/、package.json（根 / mcp-server / lmstudio-plugin）
> 官方文档：https://webbrain.one · Discord：https://discord.gg/cgC325ssfw

## 1. 项目定位

WebBrain 是一个开源（MIT）AI 浏览器 Agent 扩展：侧边栏中的 LLM Agent 能读取任何页面（文本/链接/表单/表格/PDF/交互元素，经无障碍树而非脆弱选择器）、点击、输入、滚动、导航、上传下载，自主完成多步骤任务。模型自选——本地服务、云端 API 或零配置托管默认。

## 2. 安装

### 2.1 商店安装（推荐）

| 浏览器 | 入口 |
|---|---|
| Chrome | [Chrome Web Store](https://chromewebstore.google.com/detail/webbrain/lhijonmfahplgbbacgcfnaihbjljhhb) |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/webbrain/) |
| Edge | [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/dfbioajafcijomhljabppcelecgdgfeo) |

### 2.2 从源码加载（开发用）

```bash
git clone https://github.com/webbrain-one/webbrain.git
```

- **Chrome**：打开 `chrome://extensions/` → 开启右上角 **Developer mode** → **Load unpacked** → 选择 `webbrain/src/chrome` 文件夹。
- **Firefox**：打开 `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → 选择 `src/firefox/manifest.json`（临时加载，重启即失效；永久安装需经 AMO 签名）。

无需 `npm install`、无需构建步骤——扩展为原生 ES Modules，商店版与源码版运行同一份代码。仅运行测试 / 构建官网 / 构建 zip 时才需要 Node 环境。

## 3. 基本使用

点击 WebBrain 图标（或 `Alt+Shift+W`）打开侧边面板，输入自然语言：

- "Summarize this page"（总结本页）
- "Find all links about pricing"（找出所有定价相关链接）
- "Fill in the search box with 'AI agents' and click Search"（填搜索框并点击搜索）
- "Navigate to github.com and find trending repositories"（导航并找 trending 仓库）

### 3.1 三种模式（用户授权什么）

| 模式 | 能力 |
|---|---|
| **Ask** | 只读：读页面、答题、fetch URL |
| **Act** | 点击、输入、导航、上传下载、填表单 |
| **Dev** | 增加：页面源码、样式、控制台、网络、可逆页面编辑（需 Mid/Full 层级提供商） |

**层级（tier）与模式正交**：`compact | mid | full` 是每提供商设置，控制模型可见工具数量——Compact 适合小型本地模型，Full 解锁 hover、拖放、frames、shadow DOM。

### 3.2 键盘快捷键（面板聚焦时）

| 快捷键 | 功能 |
|---|---|
| `Ctrl+/` / `Cmd+/` | 聚焦输入框 |
| `Ctrl+Shift+A` / `Cmd+Shift+A` | 切到 Ask 模式 |
| `Ctrl+Shift+X` / `Cmd+Shift+X` | 切到 Act 模式 |
| `Ctrl+Shift+D` / `Cmd+Shift+D` | 切到 Dev 模式 |
| `Escape` | 停止当前运行（双重 Escape 停止录制） |

## 4. 配置模型

**WebBrain Cloud 1.0** 为默认，无需 API key 或本地设置。

### 4.1 本地模型（同样免 API key）

指向任意 OpenAI 兼容服务器：

```bash
llama-server -m your-model.gguf --port 8080          # llama.cpp  → :8080
ollama serve                                          # Ollama     → :11434/v1
vllm serve your-model --port 8000                     # vLLM       → :8000/v1
python -m sglang.launch_server --model-path your-model --port 30000
```

LM Studio (`:1234/v1`)、Jan (`:1337/v1`)、LocalAI (`:8080/v1`)、GPT4All (`:4891/v1`) 同理；另有通用 **Local OpenAI-compatible Proxy** 卡片支持带认证的回环网关（如 CLIProxyAPI）。Chromium 还有端点无关的本地 **WebGPU** 选项（含测试过的 LFM2.5 2.6B 预设）。

**上下文窗口要求**：至少 **16k token**（8k 仅 Compact 层级可用，4k 连系统提示 + 工具 schema 都放不下）。WebBrain 会为 llama.cpp/Ollama/LM Studio 自动探测真实窗口并在填满时自动压缩对话；Model 字段留空时每回合重查已加载模型能力（服务器端热切换生效）。

### 4.2 云 API

OpenAI、Anthropic Claude、Google Gemini、Azure OpenAI、AWS Bedrock、Mistral、DeepSeek、xAI Grok、MiniMax、Kimi、Qwen、z.ai GLM、Groq、Together、Cloudflare、Nvidia NIM、Hugging Face、Fireworks、OpenRouter 等——设置内置 **106 张提供商卡片（Chromium；Firefox 105）**。完整目录见 `docs/providers-and-models.md`。

### 4.3 其他重要设置

- **Plan before Act**：Act/Dev 可先生成结构化计划、展示审批、批准后钉入 scratchpad 再执行（Try 默认）。
- **费用配额**：云/路由模型的会话/累计美元限额，超限停止调用。
- **用户记忆**：Settings → Profile（启用/自动学习/编辑/导出导入），默认关闭。
- **技能**：Settings → Skills 管理；支持导入 Agent Skills 格式 `SKILL.md`。
- **Cloud bridge**：Settings → General → Advanced，见下文 MCP 部分。

## 5. 斜杠命令（面板输入 `/help` 查看全部）

| 命令 | 作用 |
|---|---|
| `/ask` · `/act` · `/dev` · `/plan` | 发送前切换模式 |
| `/schedule [prompt]` | 创建定时任务 |
| `/watch [--keep] [--secs 30-120] [--long\|--short] <条件与动作> [/beep]` | 轮询当前页面，条件满足时行动 |
| `/workflow` · `/workflow --save <name>` | 管理保存的工作流 / 编译最近成功运行 |
| `/teach --start <name>` · `/teach --end` | 从你演示的动作学习可复用工作流 |
| `/memory --add <text>` | 保存用户偏好 |
| `/screenshot [--full-page]` | 截取视口或整页 |
| `/record [--transcribe]` | 录制当前 tab（可选保存转录） |
| `/export [--traces\|--config]` | 导出对话 / 工具链 / 设置快照 |
| `/import <json>` · `/import --file` | 导入 `webbrain-config/1` 设置 |
| `/compact` · `/reset` · `/verbose` | 压缩上下文 / 清空对话 / 切换工具详情 |
| `/allow-api` | 本对话允许 `fetch_url` 变更方法（UI 失效时的覆盖） |

两个隐藏的运行捕获后缀：`<提示> /record [--save-as <文件名>]`（Chrome 录制运行）与 `<提示> /screenshot [--save-as <文件名>]`（前后视口截图）。

`/watch` 首次检查立即执行，之后默认 60 秒轮询；相对条件（如"出现新提交时"）首轮建立基线；`--keep` 保持监视并抑制同一稳定事件键的重复告警。

## 6. 常用功能

- **每 tab 独立对话**：每个标签页保留自己的历史。
- **自动压缩**：token 感知，面板中出现"Context automatically compacted"分隔线属正常行为。
- **Continue 按钮**：达到步数上限（默认 130，可配 195）时点击继续。
- **确定性默认**：浏览器控制决策温度 0.15、Ask 0.3、视觉截图描述 0。

## 7. MCP 服务器（让编码 Agent 使用你的浏览器）

让 Claude Code / Codex / Cursor / OpenClaw 把任务委托给**你已登录**的浏览器会话——无头框架从登出状态开始并卡在登录墙，这里不会。

```bash
# 方式一：Claude Code 自动拉起
claude mcp add --transport stdio webbrain -- npx -y @webbrain/mcp-server

# 方式二：手动前台运行（Ctrl+C 停止）
npx -y @webbrain/mcp-server
```

然后：**WebBrain → Settings → General → Advanced → Cloud bridge**，URL 设为 `ws://127.0.0.1:17374/extension` 并启用。**仅 Chromium**（需 offscreen 文档；Firefox 不支持）。

六个任务级工具：`webbrain_run`（执行任务）、`webbrain_extract`（按 JSON Schema 结构化抽取）、status、clarification 应答、abort、连接诊断。示例：

```
webbrain_run(task: "open the Stripe dashboard and list last week's failed
             payments with amounts and customer emails", mode: "ask")
```

`mode='act'` 受与人类相同的浏览器内审批提示门控。若报 **Connection error: WebSocket error**：通常是没有进程监听该 URL——确认 MCP 服务器在跑、端口是 `17374`。桥接互斥：扩展同时只持一个 socket——Cloud (17373)、MCP (17374) 或 LM Studio (17375)，在设置中切换。要求 Node ≥ 20。

## 8. LM Studio 插件

```bash
lms clone webbrain/web-tools
```

`fetch_url` / `research_url` 为纯 Node HTTP（无浏览器、无 cookie、无 JS）；装有 Chromium 扩展时 `browser_task` 委托给真实已登录浏览器（Firefox 不支持 browser_task）。

## 9. 开发工作流

### 9.1 环境要求

- 日常扩展开发：**零依赖**，克隆后直接加载 `src/chrome` 即可。
- 运行测试：Node（含 `node --test` 与 ESM）+ `npm install`（playwright、tldts）。
- mcp-server / lmstudio-plugin：**Node ≥ 20** + TypeScript（`npm run build`）。
- 部分资产脚本（`npm run sync:logo`）：需要 Python 3。

### 9.2 常用命令（根 package.json）

| 命令 | 作用 |
|---|---|
| `npm test` | 工具栏守卫测试 + 主测试套件 + 安全注入语料 |
| `npm run test:security` | 仅注入语料 |
| `npm run test:injection-bench` | LLM prompt-injection 场景基准（消耗模型调用） |
| `npm run test:webmcp` | WebMCP 端到端 |
| `npm run test:ci` / `npm run ci:e2e` | CI 测试 / Playwright 端到端（`--dry-run` 干跑） |
| `npm run build:web` | 构建官网落地页 + 博客 + 文档站 |
| `npm run build:zip` | 打包扩展 zip（发布用） |
| `npm run bump` / `npm run release` | 版本号管理 |

### 9.3 贡献要点

- **加工具**：按 `docs/adding-a-tool.md` 的 checklist。
- **加提供商**：子类化 `BaseLLMProvider`，实现 `chat()`（可选 `chatStream()`），在 `providers/manager.js` 注册——**镜像修改到 `src/chrome/` 与 `src/firefox/`**。所有提供商归一化到 `{ content, toolCalls, usage }`。
- **加站点适配器**：见 `docs/site-adapters.md`（58+ 现有适配器，同时刻只激活一个）。
- 安全关键共享模块（如 rich-text-toolbar-guard）要求两构建**字节一致**，有测试守护。
- 行为准则、治理、安全政策见根目录 `CODE_OF_CONDUCT.md` / `GOVERNANCE.md` / `SECURITY.md`。

### 9.4 推荐阅读顺序（源码理解）

1. `docs/architecture.md` — 系统总览与回合流程（最佳入口）
2. `src/chrome/manifest.json` — 权限与注入结构
3. `src/chrome/src/background.js` — 消息路由
4. `src/chrome/src/agent/agent.js` — Agent 循环（26k 行，建议配合文档按子系统读）
5. `src/chrome/src/agent/tools.js` — 工具 schema 与系统提示
6. `docs/agent-tools.md`、`docs/security-model.md`、`docs/accessibility-tree-and-refs.md`

## 10. 已知限制

- **Firefox 明显弱于 Chrome**：无 `chrome.debugger` 等价物——无 shadow-DOM 穿透、无真正可信鼠标事件（部分 React/Vue 处理器不触发）、无 CDP 截图（用 `tabs.captureTab`）、无重复提交守卫；部分 SPA 客户端导航后内容脚本可能不重新注入。站点适配器、视觉检测、循环检测、自动截图循环、Compact 提示词/工具集**已**镜像到 Firefox。
- 桥接（Cloud/MCP/LM Studio）仅 Chromium。
- Alibaba Cloud (DashScope) 不支持流式（`tools` + `stream` 会被拒）。

## 11. 故障排查速查

| 症状 | 处置 |
|---|---|
| 小本地模型表现差 | 确认上下文 ≥16k；尝试 Compact 层级；Model 字段留空让能力自动重查 |
| 本地 localhost 连不上（Firefox） | 服务器需设 CORS 头（Chrome 走 offscreen 代理无此问题） |
| MCP 报 WebSocket error | 确认 `npx -y @webbrain/mcp-server` 在运行、端口 17374、扩展为 Chromium |
| 长运行后模型"失忆" | 正常自动压缩；`/compact` 手动压缩，关键信息让 Agent 写入 scratchpad（Plan 审批后自动钉入） |
| Agent 重复点击不前进 | 循环检测会自动提醒/停止；可开 API 变更观察者获取 `fetch_url` 捷径建议 |
