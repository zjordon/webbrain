## 💡 设计要点

1. **水化先于账本重置**（L24743-24748 注释）：持久化的工具栏义务不能活得比清除它的运行更久；且 `_hydrate` 是标记 busy 后第一个 await，包独立 catch 防 storage 读失败把 tab 永久卡在"运行中"。
2. **trusted 信封一次性注入**：动态可信状态（时钟、模式）放本回合用户消息而非缓存稳定的系统提示（L3841-3843 注释），规划器与执行器共享同一信封。
3. **standalone 边界**：standaloneChat 直接返回裸消息（L3838-3840），刻意不加任何浏览器派生上下文。
4. **附件先于规划门验证**：不支持的附件是"告诉用户"的纯文本响应，不是 Agent 运行，消息绝不以这种形态进历史（L25111-25113 注释）。
