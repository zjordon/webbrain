## 💡 设计要点

1. **门失败不抛异常**：每道门都以"注入结构化 tool 消息 + continue"收场——模型看到拒绝原因并能改道，运行不崩。
2. **合成结果保结构完整**：批内任何中断（abort/done/stop/deliver/保护页）都用 `_appendSyntheticToolResults` 补齐剩余 tool 消息——孤儿 `tool_calls` 会让下个请求 400（L6620-6623 注释）。
3. **守卫的时序精确性**：接收者守卫、工具栏预检在 `executeTool` 之前；审计、完成不变量、进度观察在之后——"分发前验证意图，分发后验证结果"。
4. **截图与文字配对**：自动截图附带 untrusted 包装的可点元素清单——视觉模型不再"猜像素"（L7057-7070 注释）。
5. **一次批一张图**：截图去抖 500ms + 每回合预算（`autoScreenshotCount`），批内多工具只产生一张事后图。
